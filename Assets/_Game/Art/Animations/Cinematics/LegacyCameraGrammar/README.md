# Legacy camera grammar used by the Akaza phase-two intro

`C33_Cam.fbx` and `C34_Cam.fbx` preserve the camera animation used as the
starting grammar for the Olympus Station Akaza phase-two transition.

- Source: *The Phantom Knowledge*, `Assets/Scenes/01_Master/C33/`
- C33 product crop: local 6.10-7.70 seconds (six-wing deployment)
- C34 product span: 2.366667 seconds (eye-opening close-up)
- C33 SHA-256: `6AA9F369B692894BA08DFF7DE86B3424C377382B728450A713563FE86400C2D3`
- C34 SHA-256: `8CBAD1F374DD60044CD4B228AB2D9F441FF8D927ABC73826F60528146A1E1091`

The product Timeline uses DimensionBrawl's current URP materials, lighting,
gameplay environment, combat flow, VFX, and follow-through action. The source
project's completed Timeline, audio, post-processing stack, and legacy shaders
are not imported.

These source camera animations originate from Unity Technologies Japan's
*The Phantom Knowledge* project. Preserve the applicable Unity-Chan License /
Unity Companion License attribution and third-party notice when distributing
the retained camera data.
